# Js class — Ejercicios de fundamentos JavaScript

Colección de **ejercicios de nivel básico** en archivos `.js` independientes: variables, funciones, condicionales y estructuras de control.

**Autora del repositorio:** [@Juli21v](https://github.com/Juli21v)

## Estructura del repositorio

```
Js-class/
├── index.html              # Punto de entrada opcional para enlazar scripts
└── nivelbasico/
    ├── ejercicio1.js
    ├── ejercicio2.js
    └── …                    # ejercicio3 … ejercicio16
```

## Cómo usarlos

Ejecuta los archivos con **Node.js** (`node nivelbasico/ejercicio1.js`) o inclúyelos en una página HTML para probarlos en el navegador.

## Para reclutadores

Demuestra **práctica sistemática** de la sintaxis y lógica de JavaScript antes de frameworks.
